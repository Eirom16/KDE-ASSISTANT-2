# F4-R4 — Pendientes y decisiones

Fecha: 2026-10-19. F4 permanece **PARTIAL**. No autoriza consolidación ni otra fase.

| ID | Clase | Evidencia / situación | Tratamiento |
|---|---|---|---|
| R4-LATENCY | Rendimiento | Crear una sesión ONNX sigue dominando el arranque frío; quitar la validación duplicada sólo aporta una mejora limitada. | Cifras finales en BENCHMARKS. No aumentar timeouts ni ocultar esta espera. |
| R4-STREAM-GAP | Defecto reproducible del prototipo | Piper produce «Hola.» como primer chunk muy corto; la frase siguiente no siempre llega antes de agotarlo. `supply_gap_ms` compara disponibilidad con duración PCM anterior. | Streaming directo retirado de la ruta de producción. El indicador no constituye una medición acústica, pero impide presumir continuidad. Adaptador retenido sólo para experimentos/tests. |
| R4-PREPARED | Decisión de arquitectura pendiente | Reutilizar ONNX mejora mucho la segunda síntesis, reteniendo cientos de MiB. Se midió exclusivamente un experimento Rust de dos solicitudes y TTL 3 s. | No cambiar default. Antes de integración: decidir activación, preparación/evicción, TTL configurable, RAM aceptable, salud y cancelación de solicitudes dentro de VoiceCoordinator. El prototipo no implementa esas preferencias de producto. |
| R4-COLD | Limitación técnica | El experimento preparado tampoco elimina el coste de la primera solicitud. Caché del filesystem no equivale a sesión ONNX caliente. | Evaluar política de preparación únicamente después de decisión explícita; no precargar al arrancar ni mientras voz está desactivada. |
| R4-QUALITY | Validación humana faltante | R3 T1 fue aceptada; la ruta R4 sólo pasó pruebas offline/estructura PCM y no se escuchó. Piper tiene generación estocástica: hashes/duraciones distintos no prueban cortes ni equivalencia audible. | Mantener PASS histórico de T1 sin trasladarlo a R4. Nueva escucha requiere permiso independiente después de revisión. T2–T5 humanos NOT_TESTED. |
| R4-TIMING | Límite de medición | Primer PCM, estado Speaking, spawn del reproductor y conexión al sumidero nulo son instantes diferentes. No se capturó inicio acústico. | No llamar «primer audio audible» a ninguno. Bootstrap Python se estima con reloj de pared; cancelación y deadlines usan monotónico. |
| R4-REPRO | Reproducibilidad | CPU de escritorio no dedicada; variación de carga/frecuencia y page cache no controladas globalmente. La primera exploración tenía un monitor más frecuente; una serie final fue interrumpida al detectar compilación entre inferencias. | Comparación principal alternada con monitor igual; n, dispersión y cargas registradas. Serie incompleta excluida; no desactivar guards ni terminar aplicaciones ajenas. p95 con n=5 es sólo el máximo de esa muestra. |
| R4-INODE-WINDOW | Defecto corregido antes de revisión | La identidad se recapturaba después del hash en el primer prototipo. | Conservación de identidad al terminar el hash, revalidación antes de exec y comprobación Python antes/después de cargar; test de modificación posterior PASS. |
| R4-KWIN-INTERMITTENT | Fallo observado / causa no aislada | El primer gate F3 falló «Active own window did not hide»; dos ejecuciones posteriores del runner original pasaron. | Conservar FAIL y repetición, sin modificar assertions ni atribuir causa. Gate final F3 PASS registrado por separado; causa inicial pendiente de aislar, sin afirmar ausencia de recurrencia. |
| R4-INTEGRITY | Límite de seguridad | Hashes completos por operación e inodos del modelo/config fijados. Módulos privados siguen importándose por rutas y el worker no es sandbox de filesystem contra un atacante del mismo UID. | No prometer aislamiento de seguridad total. Sin caché basada sólo en mtime ni reutilización de verificaciones antiguas. |
| R4-DISTRIBUTION | Fuera de alcance | Se conservan Piper 1.8.0 GPL-3.0-or-later y voz previamente evaluados, sin nuevos recursos. | Distribución/licencias de pesos/dataset y empaquetado siguen para revisión específica futura; no se inició F6. |
| R4-OTHER | Etapas pendientes | PTT humano R2 no se repite; wake sigue bloqueado y no se implementa. | Sin micrófono, wake, GlobalShortcuts ni F5. |

No se hicieron descargas ni instalaciones. Se conserva la instalación privada Piper autorizada y la evidencia sintética necesaria para revisión, sin hijos de voz activos al cierre. No se eliminaron recursos de R3 ni se tocó el perfil personal. Los temporales sintéticos producidos por tests se eliminan al terminar; no se generaron archivos PCM/WAV de las síntesis ni grabaciones personales.

**Dictamen:** IMPROVED limitado / TTS técnico READY_FOR_REVIEW / F4 PARTIAL. Las decisiones y pruebas humanas pendientes no se convierten en aceptación de producto. Gates finales PASS; fallo intermitente inicial conservado.

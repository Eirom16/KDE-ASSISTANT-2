## PARTIAL

- Compatibilidad genérica OpenAI-compatible: no se modelan todos los parámetros de cada familia de modelos. El servidor comunica rechazos; no hay cambios o reintentos silenciosos. `/models` carece de un esquema universal de capacidades de chat/tools.
- Corrupción: recuperación manual conservadora comprobada, sin asistente gráfico de recuperación. F1/F3 exigen fallo de arranque ante configuración inválida; no se carga una copia de forma automática que reactive capacidades.
- Se conserva el límite previo de almacenamiento privado frente a procesos hostiles del mismo UID. No hay keyring/cifrado nuevo ni eliminación forense de backups.
- La revisión optimista protege las actualizaciones del proceso autenticado. Edición manual externa o varios procesos ajenos escribiendo el mismo perfil no forman parte de ese protocolo.
- Sync fallido después de rename puede dejar durabilidad incierta. Se informa error y se conserva backup; no se certifican fallos físicos/disco lleno en ese punto ni power loss real.
- La UI conserva ajustes heredados de voz y personaje sin certificar motores, micrófono o comportamiento de overlay. No comienza F4/F5.

- Gesto humano en teclado, lector de pantalla, escala fraccional y todas las distribuciones de Plasma. Las teclas automatizadas fueron Qt Quick Test; KWin observa ventanas nativas propias.

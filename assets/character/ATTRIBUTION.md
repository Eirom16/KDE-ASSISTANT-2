# Atribución — Assistant Character

La identidad visual del personaje (silueta capsule, rasgos faciales, poses de
las 14 expresiones) deriva de **blobatar** v2.7.0, de Alain.

- Proyecto: https://github.com/Alain00/blobatar
- Documentación: https://blobatar.dev/docs
- Licencia: MIT (texto completo en LICENSE.blobatar)
- Referencia de diseño: https://blobatar.dev/?hue=225&shape=capsule

Generación: seed `kde-assistant`, `hue: 225`, `traits: { shape: 0.65 }`
(capsule de gen 2). Los SVG de referencia y el layout numérico se generaron
offline con la biblioteca y se distribuyen con la aplicación; en tiempo de
ejecución no se contacta blobatar.dev ni se requiere conexión.
